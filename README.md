# 森森造樂 Forest Play Lab

森林風格的低碳旋轉遊具選材遊戲原型。

## 玩法
選擇顯示或隱藏碳排，依序挑選主幹、拉繩與座椅；每輪五次製作機會。符合遊戲結構規則時，座椅與拉繩會繞固定主幹旋轉。比較成功作品的示範碳排。

## 執行
無需安裝依賴，以靜態網站伺服器提供 專案根目錄 即可，例如 `python3 -m http.server 8000`。

## 原型限制
- 碳排數值為未核實的示範資料，不能用於真實碳盤查。
- 結構判定僅供教學模擬，不是施工或安全認證。
- 五次限制與排行榜使用瀏覽器 localStorage，尚無多人後端。
- 材料照片為外觀示意，材料狀態以卡片文字設定為準。
